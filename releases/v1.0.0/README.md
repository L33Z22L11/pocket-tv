# Pocket TV v1.0.0

完整固件 `pocket-tv-full.bin`，安装起始地址 `0x0`。配套电脑播放脚本位于仓库根目录，协议 PTV5。社区页面安装完成后，仍需下载本仓库并运行电脑程序。

本版支持本地与网络视频、直播列表、音量/换台、启停、自动横竖屏、文字浮层及记忆、USB 自动重连。播放时提示 `ok pause`，暂停时提示 `ok play`，音量格式 `vol80`，长按提示 `hold to hide`。

Merged firmware, flash offset `0x0`. Use the matching computer player from this repository (PTV5). Installing firmware alone does not start playback. See the root README for setup and controls. SHA-256 is provided in `SHA256SUMS`.
