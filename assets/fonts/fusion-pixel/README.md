# Pocket TV Channel

Derived bitmap subset of Fusion Pixel 12px Monospaced zh_hans, release 2026.09.01.
The Chinese glyphs use an 11 × 11 ink grid within a 12px line. No rescaling.
Derived font name: Pocket TV Channel. Font data: SIL OFL 1.1; copyright and upstream licenses are included alongside this file.

Source: https://github.com/TakWolf/fusion-pixel-font/releases/tag/2026.09.01
Asset: fusion-pixel-font-12px-monospaced-bdf-v2026.09.01.zip
Extract fusion-pixel-12px-monospaced-zh_hans.bdf and run:
`python3 tools/gen_channel_font.py /path/to/font.bdf`

The fixed character set includes GB2312 level-one Chinese, ASCII and names in the current channel catalog. Unknown glyphs display a dash. Font bitmaps stay in read-only flash.
