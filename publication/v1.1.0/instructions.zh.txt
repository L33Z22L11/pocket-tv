1. 在玩法页安装本版固件，从源码仓库的 v1.1.0 Release 下载配套包。电脑安装 Python 3.10–3.13，用 USB 数据线连接设备，运行 tv.sh（macOS/Linux）或 tv.cmd（Windows）；首次运行需联网安装依赖。
2. 搜索并选中频道，按回车或点“换台”。初次音量为零。横屏短按 ↑ 减音量、↓ 加音量；竖屏相反。长按 ↑ 上一台、↓ 下一台；短按 OK 暂停/继续，长按 OK 开关帮助。
3. USB 播放无需配网。要用 Wi-Fi，保持 USB 连接，在电脑按 W 进入配网，选择扫描到的 2.4 GHz 网络、输入密码，点“连接并保存”；隐藏网络点“手动输入”。看到“Wi-Fi 已连接”及地址后重新选台。失败可改密码重试或重新扫描，换网也用此入口。电脑与设备须在可互通的局域网；不支持网页或企业认证。
4. 保持电脑程序运行。USB 断开会尝试已配对的 Wi-Fi，接回后优先 USB；设备仍需供电，切换会重新缓冲。按 Ctrl+Q 停止并退出。
